# ONEBITE-NEXT

온라인 도서 관리 시스템

## 프로젝트 구조

- **onebite-books-client**: Next.js 기반 프론트엔드
- **onebite-books-server-main**: NestJS 기반 백엔드 API

## 시작하기

### 클라이언트 실행

```bash
cd onebite-books-client/section02
npm install
npm run dev
```

### 서버 실행

```bash
cd onebite-books-server-main
npm install
npm run start:dev
```

## 기술 스택

### Frontend
- Next.js 14
- React 18
- TypeScript

### Backend
- NestJS
- Prisma
- TypeScript
